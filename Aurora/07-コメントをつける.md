# 07. テーブル・カラムにコメントをつける

## なぜコメントをつけるのか

テーブルやカラム（列）に**説明文（コメント）**をつけられる。
「この `flg` カラムって何のフラグ？」「`status` の 1 と 2 は何を表す？」といった疑問を、DB 自身に記録しておける。**後から見た人（未来の自分・チームメンバー）が助かる**ので、商用では積極的につけたい。

> 💡 コメントは DB の動作には一切影響しない。純粋にドキュメント目的。

---

## コメントをつけるコマンド：COMMENT ON

### カラム（列）にコメント

```sql
-- 書式: COMMENT ON COLUMN テーブル名.カラム名 IS 'コメント';
COMMENT ON COLUMN users.status IS 'ユーザー状態: active=有効, inactive=退会, banned=凍結';
COMMENT ON COLUMN users.email  IS 'ログインID兼連絡先。UNIQUE制約あり';
COMMENT ON COLUMN orders.amount IS '税込金額（円）。マイナス不可';
```

### テーブルにコメント

```sql
COMMENT ON TABLE users  IS '会員マスタ。認証とプロフィールを保持';
COMMENT ON TABLE orders IS '注文履歴。1注文=1行';
```

### その他の対象にもつけられる

```sql
COMMENT ON INDEX idx_users_email IS 'ログイン時のemail検索用';
COMMENT ON SCHEMA public IS 'アプリ本体のスキーマ';
COMMENT ON DATABASE appdb IS '本番アプリDB';
COMMENT ON CONSTRAINT orders_user_id_fkey ON orders IS 'usersへの外部キー';
```

---

## コメントを削除・変更する

コメントは上書き。削除は `NULL` を指定する。

```sql
-- 変更（同じコマンドで上書き）
COMMENT ON COLUMN users.status IS '新しい説明に変更';

-- 削除（NULL を入れる）
COMMENT ON COLUMN users.status IS NULL;
```

## つけたコメントを確認する

### `\d+` でテーブルとカラムのコメントを見る（一番手軽）

通常の `\d` ではなく、**`+` をつけた `\d+`** にするとコメント列が表示される。

```
appdb=> \d+ users
```
```
                              Table "public.users"
 Column |  Type   | ... | Description
--------+---------+-----+----------------------------------------------------
 id     | integer | ... |
 email  | text    | ... | ログインID兼連絡先。UNIQUE制約あり
 status | text    | ... | ユーザー状態: active=有効, inactive=退会, banned=凍結
```
一番右の **`Description`** 列がコメント。

### テーブル自体のコメントを見る

```
appdb=> \dt+ users
```
```
 Schema | Name  | ... | Description
--------+-------+-----+----------------------------
 public | users | ... | 会員マスタ。認証とプロフィールを保持
```

### SQL でまとめて確認する

```sql
-- あるテーブルの全カラムのコメントを一覧
SELECT
  a.attname       AS column_name,
  d.description   AS comment
FROM pg_class c
JOIN pg_attribute a  ON a.attrelid = c.oid AND a.attnum > 0
LEFT JOIN pg_description d ON d.objoid = c.oid AND d.objsubid = a.attnum
WHERE c.relname = 'users'
ORDER BY a.attnum;
```

psql の便利関数を使う方法（お手軽）：

```sql
SELECT col_description('users'::regclass, ordinal_position) AS comment,
       column_name
FROM information_schema.columns
WHERE table_name = 'users';

SELECT obj_description('users'::regclass);   -- テーブル自体のコメント
```

## 商用でのおすすめの書き方

### テーブル定義と一緒にコメントもファイルにまとめる

`schema.sql` の中で、`CREATE TABLE` の直後にコメントを書いておくと、定義とドキュメントが1箇所に揃う。

```sql
CREATE TABLE users (
  id         bigserial PRIMARY KEY,
  email      text NOT NULL UNIQUE,
  status     text NOT NULL DEFAULT 'active',
  created_at timestamptz NOT NULL DEFAULT now()
);

COMMENT ON TABLE  users            IS '会員マスタ';
COMMENT ON COLUMN users.id         IS '会員ID（自動採番）';
COMMENT ON COLUMN users.email      IS 'ログインID兼連絡先';
COMMENT ON COLUMN users.status     IS '状態: active/inactive/banned';
COMMENT ON COLUMN users.created_at IS '登録日時（UTC）';
```

### コメントに書くと良い内容

- **区分値の意味**：`status: 1=未処理, 2=処理中, 3=完了`
- **単位**：`amount: 金額（円・税込）`, `weight: 重さ（グラム）`
- **制約や前提**：`必須`, `NULL可`, `外部キー`, `過去日付不可`
- **由来**：`外部システムXXXから連携`

> 💡 特に「`flg`」「`type`」「`kbn`（区分）」のような**数字や記号で意味が分からない列**には必ずコメントを。半年後の自分が救われる。
