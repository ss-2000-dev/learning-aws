# 10. よく使う・知っておくと便利なコマンド集

日々の作業が楽になる psql の便利機能を集めた。困ったら `\?`（メタコマンド一覧）と `\h`（SQL構文ヘルプ）を思い出せばよい。

---

## 困った時の2大ヘルプ

```
\?              -- psql のメタコマンド（\ 系）の一覧・説明
\h              -- SQL コマンドの一覧
\h CREATE TABLE -- 特定 SQL の構文を表示（超便利。構文を忘れたら）
\h GRANT        -- GRANT の構文が全部出る
```

> 💡 `\h` は「あの構文どう書くんだっけ？」を即解決してくれる。ネット検索より速いことも多い。

---

## 表示を見やすくする

### `\x` 縦型表示（横に長い結果の必須テク）

カラムが多くて右に見切れる時、`\x` で縦型に切り替えると劇的に見やすい。

```
appdb=> \x            -- ON/OFF がトグルで切り替わる
appdb=> SELECT * FROM users WHERE id = 1;
```
```
-[ RECORD 1 ]------------------
id         | 1
email      | taro@example.com
status     | active
created_at | 2026-01-01 10:00:00+09
```

`\x auto` にすると、横に収まる時は普通の表、長い時は自動で縦型、と賢く切り替わる。

### その他の表示調整

```
\pset null '(null)'    -- NULL を "(null)" と表示（空白と区別できる）
\pset pager off        -- 長い結果でも less を使わず一気に表示
\timing                -- SQL の実行時間を表示 ON/OFF（性能確認に必須）
```

```
appdb=> \timing
Timing is on.
appdb=> SELECT count(*) FROM users;
 count
-------
 10000
Time: 12.345 ms      ← 実行時間が出る
```

## 接続・DB 切り替え

```
\conninfo        -- 今どこに繋がっているか（DB・ユーザー・ホスト）
\c dbname        -- 別のDBに接続を切り替える（connect）
\c dbname user   -- DBとユーザーを指定して繋ぎ直す
```

## 一覧・確認系（\d ファミリー）

[08-確認コマンド.md](./08-確認コマンド.md) と重複するが、よく使うものを再掲。

```
\l          -- データベース一覧
\dt         -- テーブル一覧
\d 名前      -- テーブル/ビュー/インデックスの詳細
\d+ 名前     -- ↑の詳細版（サイズ・コメント）
\du         -- ユーザー・ロール一覧
\dn         -- スキーマ一覧
\di         -- インデックス一覧
\df         -- 関数一覧
\dp         -- 権限一覧
```

`\dt *user*` のように**ワイルドカード**で絞り込める：

```
\dt *order*    -- 名前に order を含むテーブルだけ
```

## コマンドを書きやすくする

### `\e` エディタで長い SQL を書く

複雑な SQL は、その場で打つより外部エディタで書くと楽。`\e` でエディタ（vim など）が開き、保存して閉じると実行される。

```
appdb=> \e
```

### `\i` ファイルを実行

```
\i schema.sql     -- SQLファイルを読み込んで実行
```

### 履歴（ヒストリー）

- **↑ キー**：前に打ったコマンドを呼び出す（一番よく使う）
- `\s` ：これまでのコマンド履歴を表示
- `\s history.txt` ：履歴をファイルに保存

### `\g` 直前のクエリを再実行

`;` の代わりに `\g` でも実行できる。`;` を打ち忘れた時、`\g` だけで実行できる。

```
appdb=> SELECT * FROM users     ← ; 忘れた
appdb-> \g                       ← \g で実行できる
```

## 変数・繰り返し

### `\watch` 定期的に繰り返し実行（監視）

```
appdb=> SELECT count(*) FROM orders;
appdb=> \watch 5      -- 5秒ごとに直前のクエリを繰り返す（Ctrl+Cで停止）
```
処理の進捗やレコード数の増加を眺めるのに便利。

### `\set` で変数を使う

```
appdb=> \set target_id 100
appdb=> SELECT * FROM users WHERE id = :target_id;   -- :変数名 で展開
```

## データベースのバックアップ・復元（pg_dump / pg_restore）

psql とは別のコマンドだが、DB 管理の必需品。**大きな変更の前に取っておくと安心**。

```bash
# DB全体を1ファイルにバックアップ（プレーンSQL形式）
pg_dump -h <エンドポイント> -U app_user -d appdb -f backup.sql

# 特定テーブルだけバックアップ
pg_dump -h <エンドポイント> -U app_user -d appdb -t users -f users_backup.sql

# 構造（スキーマ）だけ / データだけ
pg_dump ... --schema-only -f schema_only.sql   -- 定義だけ
pg_dump ... --data-only   -f data_only.sql     -- データだけ

# カスタム形式（圧縮・並列復元できる。大規模向け）
pg_dump -h ... -U ... -d appdb -Fc -f backup.dump

# 復元
psql -h ... -U ... -d appdb -f backup.sql       -- プレーンSQL形式の復元
pg_restore -h ... -U ... -d appdb backup.dump   -- カスタム形式の復元
```

> ⚠️ Aurora には自動バックアップ・スナップショット機能があるので、DBまるごとの日次バックアップはそちらに任せる。`pg_dump` は「作業前の手動保険」「特定テーブルだけ抜きたい」時に使うとよい。

## 実行中のクエリ・接続を見る（トラブル対応）

```sql
-- 今動いているクエリ・接続を一覧
SELECT pid, usename, state, query, query_start
FROM pg_stat_activity
WHERE state != 'idle'
ORDER BY query_start;

-- 長時間ロックしている・固まったクエリを止める（pid を上で確認して指定）
SELECT pg_cancel_backend(12345);    -- 優しく中止（まずこちら）
SELECT pg_terminate_backend(12345); -- 強制切断（効かない時）
```

> ⚠️ 本番で他人のセッションを切るのは影響が大きい。pid と query をよく確認し、必要な時だけ。

## 統計・メンテナンス系

```sql
-- 統計情報を更新（実行計画の精度が上がる。大量投入の後にやると良い）
ANALYZE users;
ANALYZE;              -- 全テーブル

-- 不要領域を回収して最適化（大量DELETE後など）
VACUUM users;
VACUUM ANALYZE users;  -- 掃除＋統計更新をまとめて

-- テーブルの行数見積もり・肥大化の確認
SELECT relname, n_live_tup, n_dead_tup
FROM pg_stat_user_tables ORDER BY n_dead_tup DESC;
--  n_dead_tup（不要行）が多い → VACUUM 候補
```

> 💡 Aurora は自動 VACUUM（autovacuum）が動いているので通常は放置でよい。大量の DELETE/UPDATE の直後だけ手動 `VACUUM ANALYZE` を検討。

## psql を快適にする設定ファイル（`~/.psqlrc`）

毎回打つ設定は `~/.psqlrc` に書いておくと、起動時に自動適用される。

```bash
# ~/.psqlrc の例
\set QUIET on
\timing on                       -- 常に実行時間を表示
\x auto                          -- 長い結果は自動で縦型
\pset null '(null)'              -- NULL を見やすく
\set COMP_KEYWORD_CASE upper     -- 補完キーワードを大文字に
\set HISTSIZE 5000               -- 履歴を多めに保持
-- 危険操作の保険：ON_ERROR_STOP を常にON
\set ON_ERROR_STOP on
\set QUIET off
```

## 覚えておくと一生使える TOP5

| コマンド | 効果 |
|---|---|
| `\?` / `\h コマンド` | 困ったらヘルプ。構文を忘れても大丈夫 |
| `\d テーブル` | テーブル構造の確認（最頻出） |
| `\x` | 横長の結果を縦型で見やすく |
| `Ctrl + C` | 入力が詰まった / 変な記号が出た時の脱出 |
| `\timing` | クエリの速さを測る |
