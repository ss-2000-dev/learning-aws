今日出社したらIAM Identity Center への移行は却下されました。
理由としては組織のアカウント全体で有効化する必要があったからです。
利用しているAWSアカウントは組織メンバーアカウントで、組織管理アカウントが全アカウントに対して有効化にしない限り
私がマルチアカウント権限やPermission Setsを作成する権限をもつことを許されないためです。

そこで今度はスイッチロールを利用することになりました。
スイッチロールを利用するセッション時間は最大で何分短縮することができるでしょうか？
また、既存のCloudFormationでIAMグループ、IAMポリシーを管理しているところからスイッチロールへどのように移行すればよいのか教えて下さい。
シナリオとしては以下のテンプレートのときを想定してほしいです。
また、開発環境、検証環境、商用環境があるとき特定のユーザーは商用環境へのアクセスを制限したいです。
出力するドキュメントはそもそもスイッチロールがどういうものなのかもわかりやすく記載してほしいです。
ドキュメントの出力個所はIAM/SwithRole配下がよいです。

```yaml
AWSTemplateFormatVersion: "2010-09-09"
Description: |
  [移行前] 現状の IAM グループ定義テンプレート（サンプルシナリオ）

  - Developers（開発者グループ）: AWS 管理ポリシー PowerUserAccess をアタッチ
  - Infra（インフラグループ）: カスタムのインラインポリシーをアタッチ
    （EC2 / ELB / ASG / CloudFormation の操作は許可、IAM / Organizations の操作は明示的に拒否）

  この状態から IAM Identity Center への移行を行う。移行後の対応物は
  ../after/identity-center-groups.yaml / identity-center-permission-sets.yaml を参照。

# ==============================================================================
# Resources
# ==============================================================================
Resources:

  # ----------------------------------------------------------------------------
  # 開発者グループ（AWS 管理ポリシーを利用）
  # ----------------------------------------------------------------------------
  DevelopersGroup:
    Type: AWS::IAM::Group
    Properties:
      GroupName: DevelopersTestGroup
      ManagedPolicyArns:
        - arn:aws:iam::aws:policy/PowerUserAccess

  # ----------------------------------------------------------------------------
  # インフラグループ（カスタムのインラインポリシーを利用）
  # ----------------------------------------------------------------------------
  InfraGroup:
    Type: AWS::IAM::Group
    Properties:
      GroupName: InfraTestGroup

  InfraGroupPolicy:
    Type: AWS::IAM::Policy
    Properties:
      PolicyName: InfraGroupTestCustomPolicy
      Groups:
        - !Ref InfraGroup
      PolicyDocument:
        Version: "2012-10-17"
        Statement:
          - Sid: InfraResourceAccess
            Effect: Allow
            Action:
              - ec2:*
              - elasticloadbalancing:*
              - autoscaling:*
              - cloudformation:*
              - rds:Describe*
              - rds:List*
            Resource: "*"
          - Sid: DenyIamAndOrganizations
            Effect: Deny
            Action:
              - iam:*
              - organizations:*
            Resource: "*"

# ==============================================================================
# Outputs
# ==============================================================================
Outputs:
  DevelopersGroupName:
    Value: !Ref DevelopersGroup

  InfraGroupName:
    Value: !Ref InfraGroup
```
